# 贡献值计量详解

> 双轨制：输入端劳动价值论 + 输出端市场价值论

---

## 一、为什么需要双轨

单纯的「按工时计件」（劳动价值论）无法区分高质量产出和低质量产出。一个标注了100张猫图和10张罕见病病理切片的人，劳动投入相近，但AI时代的价值产出差几个数量级。

单纯的「事后Shapley值分配」（市场价值论）无法保障基础收入。如果标注员干了一个月发现自己的数据后来都没产生收益，等于白干。

**双轨制**：先按劳动给基础贡献值（能活），再按市场收益做事后修正（能富）。

---

## 二、轨道A：基础贡献值

### 公式

```
贡献值_A = T x A x C x S
```

| 符号 | 含义 | 计量 | 更新频率 |
|------|------|------|---------|
| T | 工时 | 系统自动记录链上时间戳 | 实时 |
| A | 准确率因子 | 质量校验层抽样验证，交叉验证+专家抽检 | 每日 |
| C | 复杂度等级 | 预定义任务分级表L1-L5，社区投票确定映射 | 试点校准后固化 |
| S | 稀缺性加权 | 根据数据类型覆盖率动态计算，覆盖率越低S越高 | 每月 |

### 复杂度等级（L1-L5）

| 等级 | 典型任务 | 权重 |
|------|---------|------|
| L1 | 通用文本分类、简单图像打标 | 1.0 |
| L2 | 专业文本标注、多标签分类 | 1.5 |
| L3 | 医疗影像分区、法律文书分类 | 2.5 |
| L4 | 罕见病标注、古籍文献识别 | 4.0 |
| L5 | 边缘案例鉴定、标注规则制定 | 6.0 |

### 准确率因子

| 准确率 | A因子 |
|--------|-------|
| >= 99.5% | 2.0 |
| >= 99.0% | 1.5 |
| >= 97.0% | 1.0 |
| >= 95.0% | 0.7 |
| < 95.0% | 0.3（触发复训） |

## 三、轨道B：市场检验修正

### 触发条件

下游数据产品产生市场化收益时触发。不产生收益则不触发修正。

### 算法框架

采用**Shapley值**或其工程近似：

对于数据产品产生收益R，上游有n个贡献节点。节点i的修正贡献值为：

```
修正贡献值_i = 初始贡献值_i x (1 + α x Shapley_i / ΣShapley)
```

其中α为修正强度系数（初始可取0.5，试点校准）。

### 工程近似方案

精确Shapley值的计算复杂度为O(2^n)，在大规模场景下不可行。本方案采用以下工程近似之一：

1. **截断蒙特卡洛采样（TMC-Shapley）**：Ghorbani & Zou (2019) 的方法，随机采样排列并计算边际贡献，在实践中O(n log n)可达到合理精度
2. **Integrated Gradients近似**：利用梯度信息估计每个数据点对模型输出的边际影响
3. **Leave-One-Out近似**（初期可用）：逐节点移除后观测性能变化

### 修正反馈回路

```
市场收益 → 反向传播 → 贡献值修正 → 分配调整 → 激励变化 → 质量提升 → 更高收益
```

## 四、轨道C：AI工具增益归算

### 原则

AI无法律人格，不参与分配。效率增益归操作者。

### 具体规则

- 标注员用AI辅助 → 效率提升10倍 → 10倍的产出贡献值归标注员
- 算法工程师用AI调参 → 增益归工程师
- 增益体现为产出量加成系数，不为AI单独开设分配科目

### 类比

用挖掘机挖土效率比铲子高，功劳归挖掘机司机，不归挖掘机制造商。制造商的价值在设备出售时实现，不在每次使用中重复分配。

### 系数设计

```
产出量加成系数 = 1 + β x (实际产出 / 标准人效基准 - 1)
```

其中β ∈ [0, 1]，控制增益分配偏向操作者还是保留在平台（初始可取β=1.0，即全部归操作者）。

## 五、轨道D：合成数据代际衰减

### 问题

人类标注一小批 → AI学习 → AI生成99%的训练数据。初始标注者该分多少？

### 数学模型

```
第N代贡献追溯权重 W_N = W_0 x r^N
```

其中：W_0 = 1.0（基准），r = 0.5（衰减率）

| 代际 | 权重 | 累计 |
|------|------|------|
| 0 | 1.000 | 1.000 |
| 1 | 0.500 | 1.500 |
| 2 | 0.250 | 1.750 |
| 3 | 0.125 | 1.875 |
| ∞ | 0.000 | 2.000 |

### 数学性质

等比级数严格收敛：Σ(0.5^N) = 2.0，N→∞

无限代际总追溯权重有限，不会出现权重爆炸。衰减规则固化在智能合约中，无需人工判断。

### 进阶

未来可引入**Influence Function**（Koh & Liang, 2017）精确计算每个初始种子数据对最终合成数据的边际影响，替代一刀切衰减系数。当前用等比衰减作为可工程化的初始近似。

## 六、治理接口

### 参数治理范围

| 参数 | 初始取值 | 治理方式 |
|------|---------|---------|
| 复杂度等级映射 | 试点社区讨论 | 链上提案+多签表决 |
| 准确率阈值 | 基准97% | 行业标准对齐 |
| 修正强度α | 0.5 | 试点数据校准 |
| 衰减率r | 0.5 | 合约写死（升级需分叉） |
| 增益系数β | 1.0 | 社区治理 |

### 参数冻结期

任何参数修改后有最短6个月的冻结期，防止频繁修改破坏参与者预期。
