# 数据要素按贡献分配 —— 顶层设计体系

---

## 体系概览

本顶层设计方案将「数据要素按贡献分配」经济模式解构为 **6个核心子系统（L0-L5）+ 2个跨切维度**（治理监管、演进路径），形成从物理底座到全民分润的完整闭环。

**数据流**：物理底座 → 数据价值链 → 贡献值计量 → 区块链存证 → 收益分配

**价值流**：市场收益 → 反向传播 → 修正上游贡献值权重

| 层级 | 子系统 | 核心功能 | 关键模块 |
|------|--------|---------|---------|
| L0 | 物理底座 | 为系统提供物理锚点 | 绿电园区 / 算力网络 / 数据存储 / 劳动力培训 |
| L1 | 数据价值链 | 数据从原始到产品的全流程 | 源接入 / 结构化 / 标注审核 / 元件化 / 交易 |
| L2 | 贡献值计量 | 量化全链条参与者的劳动贡献 | 基础贡献值 / 市场修正 / AI增益 / 合成衰减 |
| L3 | 区块链信任 | 为计量和分配提供可信底座 | 血缘账本 / 存证 / 智能合约 / DID / 隐私计算 |
| L4 | 收益分配 | 按贡献值自动执行收益分配 | SPV治理 / 成本核算 / 智能分润 / 数字人民币 |
| L5 | 生态参与 | 五类角色激励相容设计 | 数据源方 / 加工方 / 开发方 / 消费方 / 监管方 |
| — | 治理与监管（跨切） | 规则制定与合规监督 | 权重治理 / 安全合规 / 反垄断 / 仲裁 |
| — | 演进路径（跨切） | 分阶段渐进式实施 | 沙盒 → 区域 → 半开放 → 全民众包 |

---

## L0 物理底座子系统

物理底座是整个系统「不飘在空中」的锚点。数据要素分配不能建立在纯数字层之上。

| 模块 | 要素 | 对应方案 |
|------|------|---------|
| 绿电园区 | 西部园区（和林格尔、哈密等），0.30-0.38元/度 | 专报一：算电协同试点 |
| 算力网络 | 东西部SPV对价绿色算力池 | 专报一/二 |
| 数据存储 | 国家公共数据资源池，物理隔离+隐私计算 | 附件四：远景规划 |
| 劳动力培训 | 园区本地培训+断供者就业安置+远程审核认证 | 专报三：就业安置 |

**设计原则**：物理基础设施归国家/SPV共有，这是「国家掌控数据底座」的物质基础。任何市场主体可使用算力和数据，但不能控制底座本身。

## L1 数据价值链子系统

| 环节 | 功能 | 贡献值来源 | 约束 |
|------|------|-----------|------|
| 1. 数据源接入 | 政府/医院/企业提交原始数据 | 质量、稀缺性、规模 | 脱敏；持有权归全民 |
| 2. 数据结构化 | OCR/NLP将文档转为结构化数据 | 工时、准确率、复杂度 | AI辅助，人审核 |
| 3. 标注与复核 | 人工标注+AI预标+专家审核 | 工时、准确率、复杂度 | 质量校验闭环 |
| 4. 数据元件化 | 封装为标准数据元件 | 技术附加值 | 标准化接口 |
| 5. 产品化与交易 | 开发者训练模型/开发应用 | 产品创意、技术附加值 | 国家数据交易所挂牌 |

**核心设计决策**：采用「三权分置」框架——持有权归全民（国家代持），加工使用权和产品经营权依法向社会开放。

## L2 贡献值计量子系统

整个系统最核心的算法模块。**双轨制计量**。

### 轨道A：基础贡献值（输入端，实时）

基础贡献值 = 工时 x 准确率因子 x 复杂度等级 x 稀缺性加权

| 参数 | 计量方式 | 更新频率 |
|------|---------|---------|
| 工时 | 系统自动记录 | 实时 |
| 准确率 | 质量校验抽样验证 | 每日 |
| 复杂度 | 预定义分级表（L1-L5） | 试点校准后固化 |
| 稀缺性 | 数据类型覆盖率动态计算 | 每月 |

### 轨道B：市场检验修正（输出端，异步）

下游数据产品产生收益时：
- 沿链上调用图反向追溯
- 按Shapley值或其工程近似计算修正因子
- 收益越大，上游权重调整幅度越大

### 轨道C：AI工具增益归算

工具论：AI效率增益归操作者。体现为产出量加成。

### 轨道D：合成数据代际衰减

第N代权重 = 1.0 x (0.5)^N。无限代际总权重 < 2.0。

### 治理接口

初始参数试点社区公开博弈确定。后续修正通过链上治理提案表决。

## L3 区块链信任子系统

**技术选型**：联盟链（长安链/FISCO BCOS），理由：监管节点接入、数字人民币接口兼容、能耗可控。

| 模块 | 功能 | 技术手段 |
|------|------|---------|
| 数据血缘账本 | 记录数据完整路径 | 联盟链+Merkle树哈希锚定 |
| 贡献值存证 | 不可篡改贡献值记录 | 链上事件+ZKP凭证 |
| 智能合约引擎 | 规则代码化自动执行 | 多语言合约+形式化验证 |
| DID身份体系 | 五类角色身份管理 | W3C DID标准+选择性披露 |
| 隐私计算层 | 数据可用不可见 | 联邦学习+TEE+差分隐私 |

## L4 收益分配子系统

### 分配流程（固化在智能合约中）

1. 收益进入SPV托管账户
2. 扣除基础运营成本（算力、存储、平台维护）
3. 按链上贡献值比例自动分配至参与者数字钱包
4. 数字人民币结算，T+N到账
5. 税务合规，自动代扣代缴

| 模块 | 要点 |
|------|------|
| SPV法人治理 | 独立载体，隔离运营风险，第三方审计 |
| 成本核算 | 算力计费和费率透明公开，链上可查 |
| 分配频率 | 初始按月，成熟后按周/日 |
| 税务合规 | 税务机关监管节点接入联盟链 |
| 争议处理 | 链上仲裁 + 线下司法救济双通道 |

## L5 生态参与子系统（跨切）

| 角色 | 利益诉求 | 激励 | 约束 |
|------|---------|------|------|
| 数据源方 | 资产合规变现 | 持续性分成；高质量高权重 | 脱敏审核；持有权归全民 |
| 加工方 | 稳定收入+长期分红 | 基础工资+贡献值积累 | 质量考核；准入培训 |
| 开发方 | 低成本获取高质量数据 | 数据元件低价/免费 | 禁止囤积数据 |
| 消费方 | 高质量合规数据产品 | 标准化元件+质量认证 | 按市场价交易 |
| 监管方 | 穿透式审计 | 联盟链监管节点权限 | 仅监督不干预 |

---

## 治理与监管子系统（跨切）

| 模块 | 设计 |
|------|------|
| 权重治理 | 初始参数公开博弈确定；修正需链上提案表决；设参数冻结期 |
| 安全合规 | 分类分级管理；符合《数据安全法》《个人信息保护法》 |
| 反垄断 | 数据元件强制开放；单主体加工权不超过阈值 |
| 沙盒监管 | 各阶段启动前独立评估达标；设熔断阈值 |
| 争议仲裁 | 链上记录为证据；行业仲裁委员会；不服走司法 |

## 演进路径子系统（跨切）

| 阶段 | 范围 | 核心目标 | 触发条件 |
|------|------|---------|---------|
| 一 | 绿电园区封闭沙盒 | 跑通全链条闭环，校准算法 | 试点批复 |
| 二 | +1-2个东部城市 | 跨区域传输、隐私保护 | 阶段一评估达标 |
| 三 | 特定区域/技能人群 | 半开放众包，初级标注 | 社区共识达成 |

## 价值闭环

**短闭环（生产-分配）**：算力 → 文档数字化 → 数据元件 → 产品创造 → 市场收益 → 智能分润 → 激励参与 → 更多数据加工

**长闭环（反馈-进化）**：收益 → 反向修正权重 → 高质量者得更多 → 激励向高价值倾斜 → 整体质量提升 → 价格上升 → 更多收益回流

---

## 首创性说明

1. **国家底座 + 市场创新混合架构**：全球首个将国家基础设施、市场创新、全民共享纳入同一系统的方案
2. **全价值链闭环**：首次覆盖数据源→加工→产品→分配七个环节
3. **劳动价值论 + 市场价值论双轨计量**：学术界和产业界各自做到了一半，本方案首次对接
4. **AI工具论归算 + 合成数据衰减**：为AI时代特有的贡献归属问题提供了明确的数学和制度框架
