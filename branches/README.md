# 分支项目

本目录存放与「数据要素按贡献分配」方案**独立但相关**的分支项目。每个分支项目有自己的目标和文档，与核心方案共享作者和技术理念，但在逻辑上独立运作。

## 核心与分支的关系

```
                        ┌──────────────────────┐
                        │  数据按贡献分配方案   │
                        │  (核心项目)          │
                        │  贡献值计量/智能分润  │
                        └──────────┬───────────┘
                                   │
                    ┌──────────────┼──────────────┐
                    │              │              │
              ┌─────┴─────┐ ┌─────┴─────┐ ┌─────┴─────┐
              │ 绿电算力   │ │ (后续)    │ │ (后续)    │
              │ 底座方案   │ │ 行业数据   │ │ 就业培训   │
              │           │ │ 标准化     │ │ 方案       │
              └───────────┘ └───────────┘ └───────────┘
```

核心项目不绑定任何具体物理选址或政策建议。分支项目可以做具体的选址、投资架构和政策对接。
